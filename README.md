A program that writes one word to `/output/entry.txt` (13 characters, inside the 1–111 character gate): "nonrefundable". An ex as a purchase with no return policy — you paid in time, attention and years, and when it turned out faulty there was no refund counter.

## Run it

```sh
python3 main.py
```
